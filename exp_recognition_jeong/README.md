# 인식 단계 개선 실험 (담당: 정창민, 2026-09-12)

검출기(YOLO EXP 2클래스 크롭)와 파서(main `date_parser.py`)를 **고정**하고 인식 단계만 바꿔가며
dev 297장에서 통제 실험한 결과입니다. 점수 차이는 전적으로 이 구간에서 온 것입니다.

> ⚠️ **절대 수치를 `alt_pipeline_rapidocr` 의 81.89% 와 비교하지 마세요.** 검출기·인식 모델·크롭이 다릅니다.
> 옮겨 쓸 수 있는 것은 **기준선 대비 상대 개선폭**이고, 옮긴 뒤에는 재측정이 필요합니다.

## 결론 세 줄

1. 단일 전처리를 가장 잘 골라도 +13.6%p인데, 순서 정렬 + 텍스트 정규화 + 3경로 조합은 **+22.0%p**입니다.
2. 경로는 **3개면 충분**합니다(13경로 전부와 동률). 대신 **어떤 3개를 고르는지**가 2.6%p를 가릅니다.
3. 평균이 가장 나쁜 전처리(`dotclose_auto`, 통계적으로 유의한 악화)가 **조합에서는 두 번째로 뽑힙니다**.
   혼자만 살려내는 이미지가 있기 때문입니다. 단일 최적 전처리를 고르는 접근이 놓치는 지점입니다.

## 개별 개선의 근거

### 1. OCR 박스 읽는 순서 정렬 (+1.9%p, 개선 7 / 악화 1, p=0.070)
검출된 텍스트 조각을 좌표 정렬 없이 이어붙여 날짜 순서가 뒤바뀌고 있었습니다.
`2026 08 03`(정답 2026-03-08), `2026. .06.10 16:42`. 위→아래, 왼→오로 정렬(같은 줄 판정은 박스 높이의 60%).

부수 효과가 더 컸습니다. 정렬 전에는 CLAHE가 29/20(p=0.25)로 판정 불가였는데, 정렬 후 37/21(**p=0.0479**)로
유의해졌습니다. 텍스트가 뒤섞여 있으면 전처리 효과가 그 잡음에 묻힙니다.

### 2. 텍스트 정규화 6규칙 (+3.5%p, 개선 16 / 악화 3, p=0.0044)
| 규칙 | 예시 |
|---|---|
| `drop_time` | `16:42` 제거 |
| `squeeze` | `2026.07. .11` → `2026.07.11` |
| `clean` | 날짜와 무관한 문자 제거 (한글 키워드 유지) |
| `year_prefix` | `112026.03.04` → `2026.03.04` |
| `us_order` | `06/03/2027` → `2027.06.03` (정답은 6월 3일) |
| `trim_extra` | `2026.07.067` → `2026.07.06` |

**순서가 중요합니다.** 공백을 먼저 지우면 `10 16:42`가 `1016:42`로 붙어 시각 제거가 실패합니다.

### 3. 오류 원인 분해 (CLAHE + 정렬 기준)
| 원인 | 장수 | 비중 |
|---|---|---|
| 정답 | 155 | 52.2% |
| 인식 오류 (정답 숫자가 텍스트에 없음) | 72 | 24.2% |
| 파서 실패 (숫자는 읽혔는데 못 살림) | 41 | 13.8% |
| 검출 실패 (크롭 못함) | 20 | 6.7% — **회복률 0%** |
| 인식 완전실패 (글자 0개) | 9 | 3.0% |

무응답 중 정답이 NONE인 것은 **0장**입니다. 부분점수 체계에서 NONE은 0점이니 최선 추정이 항상 유리합니다.

### 4. 한국어 인식 모델 (`korean_PP-OCRv5_rec_mobile.onnx`)
같은 크롭·같은 전처리에서 단독 성능은 **더 낮습니다**(0.5836 vs 0.6543). 숫자를 더 흘립니다
(`06/03` → `065/03`, `2026 03 08` → `2026`).

그런데 두 모델의 숫자 출력이 완전히 같은 이미지는 297장 중 188장뿐이고, 한국어 모델만 맞힌 이미지가 5장,
한글 키워드를 읽는 것은 이 모델뿐입니다(74장). **교체가 아니라 4번째 경로(fallback)로 쓸 때 이득**이고,
조합 상한이 0.7486 → 0.7800으로 올라갑니다.

## 재현 방법

```bash
# 환경 (torch 불필요)
pip install rapidocr-onnxruntime opencv-python-headless pandas numpy pillow onnxruntime

# 제출 파이프라인
export ITDA_INPUT_DIR=./val_images ITDA_OUTPUT_PATH=./submission.csv
python pipeline_vote.py        # A안: 3경로 항목별 투표
python pipeline_cascade.py     # B안: 3경로 cascade

# 실험 재현
python make_split.py --labels itda_labeling_merged.csv --images <사진폴더> --out splits.csv
python yolo_scan.py --images <사진폴더> --onnx yolo_exp_mfg.onnx --out yolo_scan.csv
python sweep_ocr.py --split dev                      # 전처리 13종 스윕
python analyze_sweep.py                              # McNemar + 부트스트랩 CI
python combine_sweep.py --normalize                  # 상한·cascade·vote 계산
python gap_analysis.py --tag combo_all__m15          # 오류 원인 분해
python normalize_retry.py --policy always            # 정규화 규칙 ablation
```
